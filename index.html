Generate a Return Label

This will generate a USPS return label for download.
If you enter a Customer Email, an email will also be sent to the customer (and CC the agent if provided).
If blank, no email is sent (download only).
If provided, will be CC'd on the customer email.
What happens next?
  • A USPS return label will download as a PDF.
  • If Customer Email is filled out, Power Automate will email the label + instructions.
  • If Agent Email is filled out, it will be CC'd on that email.
